# Sistema visual

## Idea

Radar Cultural usa una **cartografía cultural viva**: una señal continua conecta territorio, espacios, conocimiento y comunidad. El radar comunica descubrimiento y relación; no funciona como un adorno aislado.

## Tokens

- Noche tinta: `#0d1321`.
- Violeta señal: `#6d4aff`.
- Coral encuentro: `#ff5b5b`.
- Jade abierto: `#19b39a`.
- Marfil frío: `#f2f4f7`.
- Vino mexicano: `#611232`.
- Oro de detalle: `#c9993e`.

Los temas claro y oscuro mantienen los mismos significados. Las superficies acrílicas necesitan borde, contraste y profundidad legibles; no deben reducir la accesibilidad.

## Tipografía y composición

La tipografía editorial de títulos usa una pila serif del sistema; el contenido y los controles usan una sans legible. La página varía el ritmo mediante secciones abiertas, una línea orbital, un modelo de datos en capas y una señal comunitaria compartida. No se convierte cada idea en una tarjeta.

## Movimiento

- Entrada cinematográfica breve y omitible con movimiento reducido.
- Barrido lento del radar.
- Revelado por scroll una sola vez.
- Parallax ligero sólo en dispositivos con puntero.
- Rebote pequeño para indicar respuesta, nunca para distraer.
- Los botones muestran carga únicamente cuando existe una transición real.
