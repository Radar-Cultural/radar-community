# Changelog

Todos los cambios relevantes de Radar Community se documentarán en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto utiliza [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Nueva landing con identidad de cartografía cultural, temas claro/oscuro y movimiento accesible.
- Base de Django REST Framework con cuentas, catálogos, lugares, eventos y moderación.
- API pública de sólo lectura versionada y contrato OpenAPI.
- Colección Postman Git-native con aserciones reutilizables del contrato público.
- Pruebas de visibilidad, filtros, validación de eventos y bloqueo de escrituras.
- `AGENTS.md` con contexto seguro para contribuciones asistidas por IA.
- CI y Dependabot para Python, Django y DRF.

### Changed

- Arquitectura y despliegue actualizados de Vercel a Nginx con Cloudflare Tunnel dedicado.
- Documentación y plantillas de contribución ampliadas para frontend, backend, API y migraciones.

## [0.1.0] - 2026-10-30

### Added

- Landing “Próximamente”.
- Diseño responsive e identidad visual inicial.
- Configuración de Vue 3, Vite y TypeScript.
- Metadatos SEO, accesibilidad y soporte para movimiento reducido.
- Configuración inicial del repositorio, colaboración y CI.
- Preparación original para despliegue estático.
